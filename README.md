# Starbucks Beverage Analysis Dashboard (Power BI)

An interactive Power BI dashboard that analyses Starbucks beverage nutrition (calories, sugar, caffeine, protein) and shows where Starbucks operates worldwide.

> Independent learning project. Not affiliated with or endorsed by Starbucks.


## Business Questions
- Which beverage categories have the most calories and caffeine?
- Which 5 drinks have the highest caffeine?
- How is the menu spread across categories?
- Where does Starbucks operate globally?

## Dashboard Features
- **KPI cards:** Total Beverages, Avg Sugar, Avg Calories, Avg Caffeine
- **Charts:** Avg Calories by Category, Avg Caffeine by Category, Beverage Category Distribution, Top 5 Highest Caffeine Beverages
- **Map:** Starbucks Global Presence by country
- **Slicers:** Protein Range and Beverage Prep
- **Design:** custom Starbucks-themed background

## Key Insights
1. Sugar has the highest average Sugar: 32.9 mg.
2. Calories has the highest average calories: 193.78 kcal.
3. Caffeine is the highest-caffeine beverage at 82 mg.
